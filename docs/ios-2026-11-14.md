# iOS layout — 2026-11-14, version 2026.11.14-15

## Changes
- A shared visible-viewport container anchors the map and all overlays. CSS uses 100dvh; VisualViewport handles toolbar/keyboard height and offset changes, including page restoration. Native pinch zoom remains enabled.
- Map canvas resizes through ResizeObserver when its container changes.
- Safe areas include left/right insets in landscape. Sheets use container-relative height; search inputs can shrink without horizontal overflow.
- Added Apple standalone/title/status-bar metadata; existing Apple icon retained.
- Touch targets for theme and map controls enlarged. Compact landscape layout keeps bottom actions available.
- Closing either search mode blurs its active input to dismiss the keyboard.
