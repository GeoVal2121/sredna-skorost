# Easy installation — 2026-11-15

Version 2026.11.15-4. Local technical checks PASS; not published.

Added a visible Install application button below the idle message and a second entry in Settings. The primary button is hidden during tracking/navigation. Both entries are hidden in standalone display mode, iOS navigator.standalone, after accepted install choice (current page only), or appinstalled.

install.js captures beforeinstallprompt early, prevents duplicate prompting and consumes each event only once, exclusively after a user click. Dismissal leaves the control available; no automatic repeated prompt. Errors or unavailable native prompts open a native accessible dialog with platform-specific manual instructions. iPhone/iPad guidance uses Safari sharing and Add to Home Screen. Android guidance uses browser installation menu; embedded browser users are directed to Chrome. No external service, dependency or service worker was added.

- node audit/install-browser-check.cjs PASS: local Chromium at 320x568, 390x664, 844x390; visible control fits; native dialog focus restoration and Escape; light/dark; iPhone guidance; tracking hides primary button; settings entry; mocked native install and installed event. External requests blocked; map style mocked.
- audit/install-button.png and audit/install-iphone-help.png visually inspected.

Limits: native installation and OS confirmation were not performed by the tests. Browser controls eligibility and may delay beforeinstallprompt until engagement criteria are met. Cannot silently install after the first visit. An ordinary browser tab cannot reliably detect every existing OS installation; no permanent installed flag is persisted. iPhone physical-device acceptance remains pending.
