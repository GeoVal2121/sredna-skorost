# Средна скорост

Уеб приложение (PWA) за следене на отсечките за контрол на средна скорост в България.

- `data.js` — отсечки (bgtoll.bg, сертифицирани от БИМ), километри, ограничения, приблизителни координати
- `core.js` — изчисленията (без UI)
- `app.js`, `index.html` — интерфейс, GPS, глас, калибрация, OSM рамки
- `tests/` — `node --test tests/core.test.js`; `python3 tests/e2e.py <папка> <изход>`

Изисква HTTPS (GitHub Pages). Работи при включен екран.
